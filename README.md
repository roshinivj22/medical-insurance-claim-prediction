# Medical Insurance Claim Prediction System

This project uses Machine Learning to predict medical insurance claim amounts based on customer details such as age, gender, BMI, smoking status, number of children, and region.

Technologies Used:
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

Model Used:
- Random Forest Regressor

Outcome:
The model predicts insurance claim amounts and helps improve decision-making in the insurance industry.
